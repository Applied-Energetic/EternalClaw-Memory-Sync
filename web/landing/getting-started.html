从本地导出开始，逐步走向账号化云同步

当前 EternalClawMemory 已支持本地导出、可选加密、URL 恢复和初版 Skill 工作流。下一阶段会接入网站注册、登录、Agent 槽位管理和密文同步。

先从本地备份开始

先掌握导出、加密和恢复流程，再接入网站化能力。

默认中文，英文可切换

页面默认显示中文，右上角可以手动切换英文阅读。

云端只存密文

账号和元数据属于网站，加密与解密属于本地设备。

安装依赖

当前核心脚本使用 Python，并依赖 `cryptography`、`requests` 和 `argon2-cffi`。先在本地环境安装这些依赖。

pip install cryptography requests argon2-cffi
建议在与你的 Openclaw 工作区一致的 Python 环境中安装依赖，避免脚本执行时出现模块缺失。

导出记忆

当前脚本默认围绕 `Agent.md`、`memory.md` 和 `Soul.md` 工作。你可以先导出明文 JSON，也可以直接加密成 `.blob`。

python scripts/backup_local.py

python scripts/backup_secure.py --password "your-password"
  • 如果你只是做本地调试或迁移，可以先导出 JSON。
  • 如果你要上传到云端或第三方存储，优先使用加密导出。

恢复记忆

恢复有两条常见路径：从本地 JSON 恢复，或从远程 URL 下载密文后在本地解密恢复。

python scripts/restore_local.py backups/backup_YYYYMMDD_HHMMSS.json

python scripts/restore_secure.py --url "https://example.com/backup.blob" --password "your-password"
推荐先把加密 blob 存在你自己控制的对象存储或网盘中，后续再逐步切换到网站化的账号和槽位管理。

在 Openclaw 中使用

`memory-sync` Skill 已发布到 ClawHub，你可以在 Openclaw 中通过自然语言触发备份和恢复工作流。

  • “Backup my current memory with password `secret123`.”
  • “Restore my memory from this link with password `secret123`.”
  • “Sync Agent 2 from my account.”
第三个例子对应未来的账号化云同步流程，仍需要后续网站后端与槽位管理能力补齐。

云同步规划

  1. 用户在网站注册账号并完成登录。
  2. 每个账号最多管理 3 个 Agent 记忆槽位。
  3. 上传加密 blob，数据库保存元数据，对象存储保存密文。
  4. 在其他设备登录账号，选择目标记忆并下载密文。
  5. 最后由本地设备完成解密与恢复，不把明文交给云端。

安全边界

  • 账号密码用于网站登录。
  • 本地解密密码只用于客户端加密与解密。
  • 云端只应该保存密文和元数据，不保存记忆明文。
  • 如果后续 Skill 接口或行为变化，需要同步更新 ClawHub 发布页和帮助文档。
