从本地导出开始，逐步走向账号化云同步

当前 EternalClawMemory 已支持本地导出、可选加密、URL 恢复和 Skill 初版使用。后续目标是在 Vercel 网站上提供注册、登录、Agent 槽位管理和密文同步能力。

1. 安装依赖

当前核心脚本使用 Python，并依赖 `cryptography`、`requests` 和 `argon2-cffi`。

pip install cryptography requests argon2-cffi

2. 准备记忆文件

当前脚本默认会尝试读取以下文件：

  • `Agent.md`
  • `memory.md`
  • `Soul.md`

3. 本地导出

不加密导出：

python scripts/backup_local.py

加密导出：

python scripts/backup_secure.py --password "your-password"

4. 导入与恢复

从本地 JSON 恢复：

python scripts/restore_local.py backups/backup_YYYYMMDD_HHMMSS.json

从远程 URL 下载密文并在本地解密恢复：

python scripts/restore_secure.py --url "https://example.com/backup.blob" --password "your-password"

5. 在 Openclaw 中使用

Skill 已发布在 ClawHub，可以通过自然语言触发备份或恢复。

  • “Backup my current memory with password `secret123`.”
  • “Restore my memory from this link with password `secret123`.”
  • “Sync Agent 2 from my account.”

6. 后续云同步规划

Step 01
网站注册与登录

用户在 Vercel 网站创建账号，后续逐步加入更完整的安全验证、登录保护与会话管理。

Step 02
每账号最多 3 个 Agent 槽位

一个账号可以管理三个独立 Agent 的记忆空间，既满足实际使用，也便于早期版本把模型和权限边界做扎实。

Step 03
云端只存密文

数据库保存用户、槽位和元数据，对象存储保存加密后的记忆包。明文与解密密码都留在本地。

Step 04
双路径导入

用户既可以手动上传本地文件导入，也可以网页登录后选择同步目标，再由本地客户端完成解密和恢复。
