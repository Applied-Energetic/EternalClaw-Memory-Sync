How It Works

01. Pack

Local script gathers your markdown memory files into a JSON bundle.

→
02. Encrypt

Bundle is encrypted with your password using Argon2id & AES-256.

→
03. Upload

The encrypted blob is securely uploaded to Vercel/GitHub storage.
