把 Openclaw 的记忆从易失上下文变成可备份、可同步、可恢复的长期资产

EternalClawMemory 为 Openclaw 提供本地导出、可选加密、远程恢复与后续云端同步能力。 设计边界很明确：加密与解密在本地完成，云端只保存密文和必要元数据。

Core Capabilities

围绕“本地可信、云端存密文”搭建的三条主线

这个项目不只是做一个备份脚本，而是在为长期的账号化记忆同步打地基。下面三项能力是整个产品的骨架。

01

本地导出

支持导出成 JSON，也支持加密成 `.blob`。在没有云功能时，用户也能先稳定保留自己的长期记忆。

02

本地加解密

加密和解密都发生在用户设备。后续即使有网站和数据库，这个边界也不会改变。

03

云端密文管理

Vercel 后端将负责注册、登录、槽位、记录和权限，但只保存密文和元数据，不保存记忆明文。

Workflow

当前可用流程与下一阶段流程

现在已经能完成本地导出和 URL 恢复。下一阶段把账号系统、数据库和每账号最多 3 个 Agent 的限制接进来。

Today

导出本地记忆

通过 `backup_local.py` 或 `backup_secure.py` 生成明文 JSON 或加密 `.blob`。

Today

上传到自管存储

在账号系统完成之前，用户可以先把加密后的 `.blob` 上传到自己控制的对象存储或网盘。

Next

网站账号与槽位

网站将允许用户注册登录，并管理最多 3 个 Agent 槽位及其对应的记忆记录。

Next

从云端恢复到本地

用户选择目标记忆后下载密文，再在本地用自己的密码解密并恢复，不把明文交给云端。
