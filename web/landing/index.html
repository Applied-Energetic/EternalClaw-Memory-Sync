原生 Skill 集成

作为 Openclaw Skill 使用，不需要记复杂命令，直接通过自然语言触发备份和恢复。

工作原理

01. 打包

本地脚本读取 Markdown 记忆文件并整理为 JSON 数据包。

02. 加密

使用 Argon2id 与 AES-256-GCM 在本地完成加密，保护长期记忆内容。

03. 同步 / 恢复

你可以本地保存、上传到自管存储，或在后续网站账号体系中选择密文进行同步和恢复。
