Getting Started

EternalClawMemory currently supports local export, optional encryption, restore from URL, and an initial Openclaw skill workflow. The next phase adds registration, login, agent slots, and ciphertext-only cloud sync on Vercel.

Install dependencies

pip install cryptography requests argon2-cffi

Export locally

python scripts/backup_local.py

python scripts/backup_secure.py --password "your-password"

Restore

python scripts/restore_local.py backups/backup_YYYYMMDD_HHMMSS.json

python scripts/restore_secure.py --url "https://example.com/backup.blob" --password "your-password"

Cloud direction

The planned product flow is: register on the website, manage up to 3 agent slots, upload encrypted blobs, select a memory to restore, download ciphertext, then decrypt locally.
