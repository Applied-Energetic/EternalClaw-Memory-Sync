Turn Openclaw memory into a portable, encrypted, restorable asset

EternalClawMemory provides local export, optional client-side encryption, remote restore, and the foundation for future account-based cloud sync. Encryption and decryption stay local; the cloud stores ciphertext and metadata only.

Current direction

The project is moving from a secure local backup prototype toward an account-based ciphertext sync product, with up to 3 agent slots per account and a Vercel-managed backend.
