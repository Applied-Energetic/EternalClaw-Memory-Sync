# 产品规划

[English Version](Product_Plan.en.md)

## 愿景

EternalClawMemory 要成为 Openclaw 的安全记忆操作层：

- 给进阶用户提供本地导出和恢复
- 给普通用户提供网站化的引导流程
- 给重视隐私的用户提供零知识密文同步

## 产品范围

### A. 本地记忆操作

- 不加密导出
- 加密导出
- 从本地文件导入
- 从远程 URL 导入

### B. 云端记忆操作

- 账号注册
- 登录与退出
- Dashboard 查看记录
- 上传加密记忆包
- 选择并恢复某一份记忆
- 每账号最多 3 个 Agent 槽位

### C. Openclaw 集成

Skill 需要帮助用户：

- 备份当前记忆
- 从链接恢复
- 后续从云端账号流程恢复

## 功能需求

### 账号和认证

- 邮箱/密码注册
- 安全登录
- 密码重置
- 可选邮箱验证
- 后续 2FA

### 记忆管理

- 每账号创建最多 3 个槽位
- 上传记忆到指定槽位
- 按槽位列出记录
- 恢复指定记录
- 明确地删除或替换记录

### 同步模型

- 支持手动上传
- 支持网页交互式云同步
- 下载后仍在本地解密

## MVP

云端 MVP 应至少包含：

1. 注册和登录
2. 一个基础 dashboard
3. 每账号最多 3 个槽位
4. 加密 blob 上传
5. 加密 blob 列表与下载
6. 网站内置 Getting Started 文档

## 风险

### 产品风险

如果文档承诺的功能超前于实现，用户会以为能力已经上线。

### 安全风险

如果认证和加密边界设计不清，云端可能意外接触不该接触的敏感信息。

### UX 风险

如果“账号密码”和“本地解密密码”的区别没有讲清楚，恢复流程会让用户困惑。
