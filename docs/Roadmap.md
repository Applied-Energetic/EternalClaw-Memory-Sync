# 路线图

[English Version](Roadmap.en.md)

## 当前目标

路线图围绕以下目标展开：

- 支持本地导出，可选加密或不加密
- 支持上传密文到云端
- 支持从本地文件、URL 或云账号恢复
- 每个账号最多管理 3 个 Agent 记忆
- 只要启用加密，解密就必须留在本地
