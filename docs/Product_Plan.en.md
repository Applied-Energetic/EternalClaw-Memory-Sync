# Product Plan

[中文版本](Product_Plan.md)

## Vision

EternalClawMemory should become a secure memory operating layer for Openclaw:

- local export and restore for power users
- simple website flows for normal users
- zero-knowledge encrypted cloud sync for privacy-sensitive users

## MVP

1. account registration and login
2. one dashboard page
3. up to three agent slots per account
4. encrypted blob upload
5. encrypted blob listing and download
6. website-integrated getting-started docs
