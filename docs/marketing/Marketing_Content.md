## 3. 常见问题解答 (FAQ for Marketing)

*   **Q: 如果我也忘了密码怎么办？**
    *   **A:** 非常抱歉，由于我们采用了零知识（Zero-Knowledge）加密架构，没有密码连我们也无法恢复您的数据。请务必保管好您的密钥（密码）。
*   **Q: 这会消耗很多流量吗？**
    *   **A:** 只有文本记忆会被打包，通常文件非常小（几百KB），对流量几乎没有影响。
*   **Q: 支持哪些平台？**
    *   **A:** 只要能运行 Openclaw 并支持 Python 环境的平台（Windows, Linux, macOS）均可使用。
