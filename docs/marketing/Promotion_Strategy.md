# EternalClawMemory 宣传推广策略 (Promotion Strategy)

## 1. 渠道布局 (Channels)

### 核心技术社区
*   **GitHub Trending:** 通过完善的 README、高质量的代码和 commit 活跃度冲击 Trending 榜单。
*   **Hacker News:** 以 "Show HN: Encrypted Memory Sync for AI Agents" 为题发布，强调隐私技术。
*   **Product Hunt:** 准备精美的演示视频和 GIF，发布 Launch。

### AI 垂直社区
*   **Openclaw Discord:** 在 `#showcase` 或 `#plugins` 频道发布，提供专门的 Discord 用户支持。
*   **Reddit r/LocalLLaMA & r/OpenAI:** 发布技术贴，讨论 "How to secure your local agent's memory"。
*   **X (Twitter):** 利用 AI 圈KOL（意见领袖）进行转发，使用 `#AI #Privacy #OpenSource` 标签。

## 2. 推广物料 (Assets)

*   **演示视频 (Demo Video):**
    *   录制一段 30 秒的视频：
        1.  用户对 Openclaw 说 "备份记忆"。
        2.  脚本自动运行，显示 "Encrypted & Uploaded"。
        3.  用户删除本地文件（模拟数据丢失）。
        4.  用户说 "恢复记忆"，输入密码。
        5.  记忆瞬间恢复。
*   **架构图海报:** 将 Mermaid 架构图美化为高科技风格的海报，用于博客和推文。

## 3. 增长黑客策略 (Growth Hacks)

*   **"灵魂密钥" 活动:** 前 50 名 Star 项目的用户，我们将赠送一段定制的 "初始灵魂设定" (Soul Prompt)，帮助他们建立更有趣的 Agent。
*   **嵌入式推广:** 在 Skill 的输出日志中，低调地加入 `Powered by EternalClawMemory`，随着用户分享日志而传播。
*   **协作开发:** 邀请 Openclaw 的核心贡献者 Review 代码，争取被官方收录为推荐插件。

## 4. 宣传落地页 (Landing Page)

我们将构建一个独立的静态 HTML 页面 (`web/landing/index.html`)，托管在 GitHub Pages 或 Vercel 上。
*   **风格:** 极简、暗黑模式、绿色终端字体。
*   **行动号召 (CTA):** "Get Waitlisted" 或 "View on GitHub"。
